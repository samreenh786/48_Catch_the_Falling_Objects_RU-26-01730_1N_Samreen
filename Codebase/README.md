# 🎮 Catch the Falling Objects (PS 48)

A Python-based game developed using Pygame. The player controls a basket to catch falling objects. Each successful catch increases the score, while every missed object reduces a life.

## ✨ Features

- 🎯 Catch falling objects using a basket.
- ⬅️➡️ Move the basket using LEFT and RIGHT arrow keys.
- 🏆 Score increases with every successful catch.
- ❤️ Three lives are provided.
- 📉 Missing an object reduces one life.
- 🚫 Basket movement is restricted within the game window.
- 🎮 Game Over screen displays the final score.

## 🛠️ Technologies Used

- Python 3
- Pygame
- Random Module
- Coordinates and Collision Detection
- Loops and Conditional Statements

## ▶️ How to Run

1. Install Python 3.
2. Install Pygame:

`pip install pygame`

3. Run the Python file:

`python main.py`

## 🧪 Test Cases

| Test Case | Expected Result |
|---|---|
| Normal Catch | Score increases by 1 |
| Boundary Input | Basket stays inside the window |
| Invalid Key | Key ignored |
| Missed Object | Life decreases by 1 |
| Zero Lives | Game Over with final score |
